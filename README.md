## 🚀 快速开始

### 1. 运行接口自动化（Pytest + Requests）

```bash
# 进入接口测试目录
cd 03-接口测试

# 安装依赖
pip install pytest requests allure-pytest pytest-html PyYAML openpyxl

# 运行测试 + 生成 Allure 报告
pytest -s -v --alluredir=./allure-results
allure serve ./allure-results

# 或者一键运行（Windows）
run_api_test.bat
```

### 2. 导入 Postman 集合

1. 打开 Postman → Import → 选择 `03-接口测试/Postman-集合-某教育-v1.0.json`
2. 导入环境变量 `Postman-环境变量-测试环境.json`
3. 设置 baseUrl 为 `http://test.ziweiedu.com:8080`
4. Run Collection → 配合 Newman 可做 CI 集成

### 3. JMeter 性能压测

```bash
# 打开 JMeter GUI 查看脚本
jmeter -t 04-性能测试/JMeter-核心场景.jmx

# 无界面压测 + 生成报告
jmeter -n -t JMeter-核心场景.jmx -l result.jtl -e -o ./report
```
